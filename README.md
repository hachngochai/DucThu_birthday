# 🎂 Birthday VR — Nguyễn Đức Thụ

Website sinh nhật 3D tương tác, lời chúc thân tình xưng **em**, được triển khai độc lập từ nền Birthday VR V3.

## 🌐 View Demo

**[MỞ WEBSITE SINH NHẬT NGUYỄN ĐỨC THỤ](https://hachngochai.github.io/DucThu_birthday/)**

> Nếu link chưa truy cập được, cần bật GitHub Pages ở **Settings → Pages → Deploy from a branch → main → / (root) → Save** và đợi triển khai thành công.

## ✨ Concept riêng

- tone xanh lá, nhân vật ngồi câu cá, có cần câu, mặt hồ và chim bay.
- Có nút chuyển **☀ Ngày / ☾ Đêm**.
- Mở hộp quà, khám phá nhân vật, cắm 5 nến trên bánh sinh nhật, thổi nến bằng micro hoặc thao tác thay thế, nghe nhạc Happy Birthday và mở lá thư.
- Nhãn tương tác 3D; tối ưu mobile; có hỗ trợ WebXR cho thiết bị tương thích.
- Lá thư có tiêu đề **Gửi em Thụ**.

## 🛠 Chạy thử

```bash
python -m http.server 5500
```

Mở http://localhost:5500/; cần internet để tải Three.js và Google Fonts.
